# Samples

Every person, employer, school, and job posting in this folder is fictional. The files were written for this project so the pipeline can be tried without real candidate data. Do not replace them with real resumes.

Regenerate the PDFs after editing the text in `generate_pdfs.py`:

```bash
python3 samples/generate_pdfs.py
```
